# GreyWork UI 设计方案

> 定位：面向通用人群、开发者、数据分析师与创意工作者的“空间任务控制台”。
> 设计对象：Tauri 桌面端 / Web 端共享的工作台界面。
> **视觉语言（2026-08-26 v6 更新）：机加工工作台 · 仪表面板**——GreyWork = 石墨与钢：
> 暖石墨机加工面板、仪表琥珀信号色、LED 状态语义、铭牌式大写标签（Archivo 扩展字宽）、
> JetBrains Mono 遥测读数。权限档位即机器护栏（完全执行 = 警示条纹），气质是车间设备，
> 不是聊天软件，也不是通用 SaaS 仪表盘。

## 设计关键词

- 空间仪表（instrumentation）：每一条信息都有读数与状态
- 一切皆插件：Skill / Extension / MCP 以卡片形式可发现、可安装
- 多层融合：Agent 环（紫）、GIS 图层（青）、3D 核心（琥珀）
- **多色 Agent 系统**：不同 Agent / 模块使用不同主题色（蓝 / 绿 / 橙 / 紫 / 红）

信号语义：琥珀 = 待命/武装/关键操作；mint = 在线/成功；钢蓝（`--cyan`）= 信息/执行中；

## 字体
- 栈：`--font-ui` = Archivo Variable（DIN 系工业怪诞，wdth 轴；铭牌/品牌用 125% 扩展字宽 + 大写宽字距）+ "Noto Sans SC"/"Microsoft YaHei" 中文回退
- 遥测：`--font-mono` = JetBrains Mono Variable（标签/读数/代码，大写小间距 0.1-0.22em）
- 标题：700-800 字重，24-32px（页面标题 30px，可加 110% 字宽）
- 正文：400 字重，13.5-16px
- 字体经 @fontsource-variable 本地打包（`@fontsource-variable/archivo`、`@fontsource-variable/jetbrains-mono`），离线可用

## 布局（指挥中心五区 · 2026-08-26）

- **左侧栏（260px，可收起，<1180 默认收起）**：返回/前进、新对话、搜索、主舞台导航（Chat·Cowork / Agents / 数据洞察 / 插件市场 / 自动化；无总览、无工作区——文件查看/编辑在右栏）、Projects 线程组树（状态点：运行=呼吸、待审阅=amber、完成=✓）、底部 Chats + **设置（左下角）** + 头像
- **顶栏（56px）**：GREYWORK 铭牌（扩展字宽大写 + 琥珀 LED）、项目/会话面包屑、Local/Worktree/Cloud 运行模式胶囊（选中=琥珀）、模型选择、动作组（IDE/侧栏与右栏开合）
- **主舞台（自适应）**：Cowork 即主页（`/` 重定向 chat），其余视图经侧栏入口切换，0.2s 淡入上滑切换
- **右侧边栏（420px，可开合，<1400 缩至 300px）**：标签序 **文件**（OS 式文件列表占满 → 点击文件进入内容：返回 + CodeMirror 编辑/预览 + 保存，置顶）/ Diff / 预览 / 终端 / 交付物（含最新 Markdown 产物预览）/ Review / Sources；Diff 含 Commit（真实）/ Push·Create PR（禁用待远程后端）
- **底部状态栏（24px）**：mono 仪表读数（字距 0.06em）：Git 分支 | Token 用量（未接入 → —）| 连接 LED（ACP 就绪 / Web 预览）
- **Composer（签名元素）**：输入井下陷暗井；方形琥珀武装发送键（执行中=橙色停止）；权限护栏三档（只读=琥珀 / 允许编辑=钢蓝 / 完全执行=警示条纹）；推理刀片 low/medium/high/xhigh；计划模式开关；Enter/Cmd+Enter 提交，Shift+Enter 换行；ACP 派发簇保留
- 响应式：>1400 全五区；1180-1400 右栏 300px；640-1180 右栏让位（网格折叠）；<640 单栏 + 底部 Tab 导航
- Agent 消息支持轻量 Markdown：围栏代码块（路径标签 + 行号 + 复制）、行内 code、粗体、链接（无 v-html）

## 签名元素：派工控制台（Composer）

Cowork 的心脏是派任务的地方，签名预算全部花在这里：

- **输入井**：composer 内嵌下陷暗井（`--ink` 底 + inset 阴影），附件 + 与发送键落在井内
- **武装发送**：方形琥珀按键（8px 圆角），禁用=面板灰、悬停=`--accent-hi` 亮阶；执行中变橙色停止键
- **权限护栏簇**：三档 = 机器护栏——只读=琥珀待命、允许编辑=钢蓝、**完全执行=警示条纹**（45° 橙纹 + 橙描边：危险能力上膛的视觉语言）
- **推理刀片**：low/medium/high/xhigh（mono），选中=琥珀
- **空态 = 铭牌 + 工单**：`COWORK · 派工台` 刻线眉标、琥珀铭牌徽标、四张工单卡（类型章 报告/测试/重构/分析 + 派发符 ↵）

## 次签名：GreyWork Core（3D 空间页，暂时下线）

3D 空间页使用可交互画布：

- 经纬网格 + 地形点云构成的旋转数字地球
- 三条彩色 Orbit Ring：规划环（琥珀）、地理环（青）、空间环（紫）
- 拖拽旋转、悬停查看 Agent 节点、自动旋转（尊重 reduced-motion）
- 四角读数：坐标 / 方位角 / 俯仰角 / 节点数

## 核心组件规范（AionUI）

- **Agent 卡片**：圆头像（彩色底 + 首字母）+ 名称 + 职业标签 + 状态灯 + 彩色进度条
- **协作看板**：列 = Agent（头像 + 实时状态），卡 = 子任务，左侧 4px 彩边表示优先级
- **消息气泡**：用户右对齐 `--panel-2` 圆角 16/16/4/16；Agent 左对齐 `--panel` + 左侧 3px 主题色竖线（会话 Agent 紫）
- **状态指示器**：运行中绿脉冲 / 空闲灰空环 / 执行中蓝旋转环 / 完成绿实心 / 阻塞红
- **输入区**：见「签名元素：派工控制台」；textarea 自动增高至 200px
- **微交互**：卡片 hover 上浮 4px、按钮点击 scale(0.97)、消息从下滑入（cubic-bezier(0.16,1,0.3,1)）、打字指示三圆点

## 视图清单

1. 对话 Chat（主页）：会话头（40px 头像 / 状态 / 模型下拉）+ 气泡流 + 计划卡 + 步骤卡 + 操作栏
2. Agent 协作：协作看板 + 编队卡 + 编排流水线 + 循环策略（命令守卫）
3. 3D 空间：图层控制 + GreyWork Core（Spatial Mode）+ 数据源（暂时下线）
4. GIS 地图：图层开关 + 点阵世界地图（可点击要素）+ 要素列表（暂时下线）
5. 数据洞察：数据集 + 空间 SQL + 结果表 + 聚合柱状图
6. 插件市场：分类 Pill 组 + 插件卡（彩色类型图标）+ 详情安装面板 + 远程技能 + MCP Registry
7. 自动化：任务列表 + 开关
8. 设置：左侧导航 + 模型卡片式选择器 + CLI 接入 + 推理等级 + MCP 服务器开关列表 + 通用（入口固定在侧栏左下角）
